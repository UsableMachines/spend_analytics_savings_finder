What is Spend Analytics Savings Finder?

This application analyzes your procurement spend to uncover savings opportunities, supplier consolidation candidates, contract leakage, and maverick purchasing patterns. It integrates with a Kindo AI agent to provide intelligent, data-driven recommendations.

2

Prerequisites

Before you begin, ensure you have:

  • An admin account (default: admin / admin — change the password immediately)
  • Your procurement spend data (CSV or manual entry)
  • For AI analysis: KINDO_API_TOKEN and KINDO_AGENT_ID environment variables configured
3

Add Your Suppliers

Navigate to Suppliers in the sidebar and add your vendor base. Categorize each supplier (IT, Office Supplies, Professional Services, etc.) to enable category-level analysis.

4

Set Up Contracts

Go to Contracts and enter your active agreements. Include start/end dates and total values. Linking spend to contracts enables the AI to detect contract leakage — spend that occurs outside negotiated terms.

5

Record Your Spend

Add spend records individually via Spend Records → Add, or bulk import via CSV using the API endpoint POST /api/spend/import. Flag maverick purchases to track off-contract spending.

CSV format: supplier, description, amount, category, date, po_number, department, is_maverick

6

Run AI Analysis

Go to Analysis → New Analysis. Choose an analysis type (Full Analysis, Recommendations, Validation, or Enrichment). The Kindo AI agent will process your data and return findings with actionable recommendations.

7

Next Steps

Review the Dashboard regularly for trends. Prioritize high-severity findings. Use the Admin panel to add team members with appropriate roles (Analyst for data entry, Viewer for read-only access). Re-run analyses periodically as new spend data is recorded.
